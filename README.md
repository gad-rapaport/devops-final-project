# SmartRecipe AI 🍳

An AI-powered recipe generation and management platform. Users input their available ingredients and receive personalized, complete recipes generated by Google Gemini AI. Recipes are stored in MySQL, served via a Flask REST API, proxied through Nginx, and the entire stack runs in Docker.

---

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                        User Browser                          │
└────────────────────────┬────────────────────────────────────┘
                         │ HTTP :80
┌────────────────────────▼────────────────────────────────────┐
│                   Nginx (Frontend + Proxy)                    │
│  Serves static HTML/CSS/JS  │  Proxies /api/* → Backend      │
└────────────────────────┬────────────────────────────────────┘
                         │ HTTP :5000
┌────────────────────────▼────────────────────────────────────┐
│               Flask Backend (Python 3.12 + Gunicorn)         │
│  REST API · SQLAlchemy ORM · Gemini AI integration           │
│  Prometheus metrics exporter (/metrics)                      │
└──────────────┬──────────────────────┬───────────────────────┘
               │                      │
┌──────────────▼──────────┐  ┌────────▼──────────────────────┐
│   MySQL 8.0 Database    │  │   Google Gemini API (external) │
│   recipes table         │  │   gemini-1.5-flash model       │
└─────────────────────────┘  └────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│             Monitoring Stack                                 │
│  Prometheus :9090  →  Grafana :3000                          │
└─────────────────────────────────────────────────────────────┘
```

| Layer | Technology |
|---|---|
| Frontend | HTML5 / CSS3 / Vanilla JS |
| Proxy | Nginx 1.27 |
| Backend | Python 3.12, Flask 3.0, Gunicorn |
| Database | MySQL 8.0 + SQLAlchemy + Flask-Migrate |

## Quick Start (Local)

```bash
# 1. Clone the repository
git clone git@github.com:dshrppury/devops-final-project.git
cd devops-final-project

# 2. Configure environment
cp .env.example .env
# Edit .env and set GEMINI_API_KEY and other secrets

# 3. Start all services
docker compose up -d --build

# 4. Run database migrations
docker compose exec backend flask db upgrade

# 5. Open the app
open http://localhost:80

# Grafana dashboard
open http://localhost:3000   # admin / admin (change after first login)

# Prometheus
open http://localhost:9090
```

## API Reference

| Method | Endpoint | Description |
|---|---|---|
| GET | `/health` | Health check + DB status |
| GET | `/api/recipes` | List saved recipes (paginated) |
| GET | `/api/recipes/:id` | Get single recipe |
| POST | `/api/recipes/generate` | Generate recipe with Gemini AI |
| POST | `/api/recipes` | Save a recipe |
| PUT | `/api/recipes/:id` | Update a recipe |
| DELETE | `/api/recipes/:id` | Delete a recipe |
| GET | `/api/recipes/:id/variations` | Get AI-suggested variations |
| GET | `/metrics` | Prometheus metrics |

### Generate Recipe (POST /api/recipes/generate)

```json
{
  "ingredients": ["chicken", "lemon", "garlic", "rosemary"],
  "preferences": "gluten-free"
}
```

## Running Tests

Tests use pytest against a real MySQL instance.

```bash
# Using Docker Compose (recommended for CI parity)
docker compose run --rm \
  -e TEST_DATABASE_URL=mysql+pymysql://smartrecipe:smartrecipe@db:3306/smartrecipe_test \
  backend pytest -v

# Locally (requires MySQL running on port 3307)
cd backend
pip install -r requirements.txt -r requirements-test.txt
TEST_DATABASE_URL=mysql+pymysql://smartrecipe:smartrecipe@localhost:3307/smartrecipe_test \
  pytest -v
```

## CI/CD Pipeline (GitHub Actions)

The pipeline has three sequential jobs:

```
Push to main
     │
     ▼
[1] test          — spin up MySQL service, run pytest suite
     │ (pass)
     ▼
[2] build-push    — build Docker images, push to Docker Hub with :latest + :sha-<hash> tags
     │ (push only)
     ▼
[3] deploy        — SCP compose files to Hetzner, SSH in, run deploy.sh
```

### Required GitHub Secrets

| Secret | Description |
|---|---|
| `DOCKER_HUB_USERNAME` | Docker Hub username |
| `DOCKER_HUB_TOKEN` | Docker Hub access token |
| `HETZNER_HOST` | Server IP or hostname |
| `HETZNER_USER` | SSH user (e.g. `deploy`) |
| `HETZNER_SSH_KEY` | Private SSH key for server access |

## Server Setup (Hetzner)

```bash
# On a fresh Hetzner Ubuntu 22.04 server
sudo bash infrastructure/hetzner_setup.sh

# Copy .env file to server
scp .env deploy@<server-ip>:/opt/smartrecipe/.env
```

The setup script installs Docker, configures UFW firewall, creates a `deploy` user, and prepares persistent data directories.

  - HTTP request rate per endpoint
  - p95 request latency
  - Total request count
  - 5xx error rate
